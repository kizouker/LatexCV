\section*{Professionell profil}

Civilingenjör i datateknik (Linköpings tekniska högskola) och systemutvecklare med lång erfarenhet av backendutveckling, systemintegration och databasdesign i komplexa enterprise-miljöer inom bank, offentlig sektor och telekom. Söker nu AW Accelerate för att växla spår mot Data Engineering -- inte för att börja om, utan för att bygga vidare på en stabil grund inom SQL, objektorienterad programmering och molnkoncept.

Jag har redan tagit Microsoft Azure Fundamentals (AZ-900) och gått en praktisk kurs i Cloud Computing och Azure (ReDI School), vilket ger mig ett försprång in i programmets certifieringsspår mot DP-203 och Databricks Certified Data Engineer Associate. Jag skriver Java och Python i det dagliga arbetet, och motiveras av att automatisera flöden som leder till pipelines av plattformar som gör data tillgänglig, pålitlig och användbar -- och av att kombinera min tekniska bredd med ett helhetsperspektiv på hur data skapar verksamhetsnytta.
