\section{Cybersecurity Focus and Learning Roadmap}

Currently expanding expertise in application security and penetration testing,
with a focus on understanding attack surfaces in technologies previously used in development work.

\begin{itemize}

\item \textbf{Web Application Security} – studying OWASP Top 10 vulnerabilities and how they manifest in modern web stacks such as Spring, Angular and WordPress.

\item \textbf{API Security} – exploring security considerations in REST and GraphQL APIs, including authentication, authorization and data exposure risks.

\item \textbf{Enterprise Java Security} – reviewing historical vulnerabilities in frameworks such as Struts and Spring to understand exploitation patterns and mitigation strategies.

\item \textbf{Container and Cloud Security} – learning security considerations for Docker and Kubernetes environments.

\item \textbf{Practical Pentesting Platforms} – hands-on learning through environments such as Hack The Box and OWASP vulnerable applications.

\end{itemize}
