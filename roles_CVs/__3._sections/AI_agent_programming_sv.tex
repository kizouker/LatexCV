\section{Programmering med AI-agenter}
\cvitem{}{
Aktuell, praktisk erfarenhet av att leda AI-kodningsagenter (Claude Code och liknande LLM-baserade verktyg)
genom att planera, skriva, felsöka och leverera riktig mjukvara -- från små skript till flerfilsprojekt med
versionshantering, automatiserade byggen och driftsättning. Bekväm med att förklara, på en nivå anpassad
för elever i alla åldrar, hur dessa verktyg faktiskt fungerar och var deras begränsningar finns, snarare än
att behandla dem som magi.
}
\cvitem{Agentbaserad kodning}{Att leda AI-agenter genom flerstegs programmeringsuppgifter: planering,
verktygsanvändning, iterativ felsökning och kodgranskning}
\cvitem{Praktiska projekt}{En iOS-app för HRV och andningsbaserad biofeedback, byggd med AI-agenthjälp
från start till mål}
\cvitem{Grund}{20+ års yrkeserfarenhet av mjukvaruutveckling (Java, JavaScript/TypeScript, Python) som
ligger bakom förmågan att leda och verifiera AI-genererad kod}
\cvitem{Pedagogisk vinkel}{Väl lämpad för att introducera programmeringsbegrepp genom AI-assisterad
kodning -- sänker tröskeln till ett första fungerande program samtidigt som den underliggande logiken
förklaras}
