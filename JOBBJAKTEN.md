# Jobbjakten

*Dress your CV in LaTeX with von Claude AI.*

En samlingsplats för idéer innan de blir konkreta nog för ett GitHub Issue.
Flödet är: **idé här → tillräckligt konkret → GitHub Issue → läggs till i
"Jobbjakten"-projektet (Kanban-board under repots Projects-flik)**.

Kategorierna nedan speglar mapparna som redan finns under `processes/` och
`roles_CVs/` — så en idé hamnar nära där den faktiskt kommer att genomföras.
